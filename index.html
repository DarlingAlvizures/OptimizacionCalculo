1
Diseño óptimo de una lata cilíndrica
Minimizar superficie total dado volumen fijo V = 355 mL
1 Contexto

Se desea fabricar una lata cilíndrica con volumen fijo V = 355 cm³ (equivalente a 355 mL). El objetivo es minimizar el material utilizado, es decir, minimizar la superficie total del cilindro.

La superficie total incluye dos tapas circulares (arriba y abajo) y la pared lateral.

2 Función objetivo

La función de costo (superficie total) en términos del radio r se obtiene sustituyendo la altura h = 355/(πr²):

Superficie total: S(r) = 2πr² + 2πr·h Restricción: V = πr²h = 355 → h = 355/(πr²) Sustituyendo h: C(r) = 2πr² + 2πr · [355/(πr²)] C(r) = 2πr² + 710/r

Esta es la función que se debe minimizar.

3 Derivar la función
C(r) = 2πr² + 710r⁻¹ C'(r) = d/dr[2πr²] + d/dr[710r⁻¹] C'(r) = 4πr − 710/r²
4 Puntos críticos

Igualamos C'(r) = 0:

4πr − 710/r² = 0 4πr = 710/r² 4πr³ = 710 r³ = 710/(4π) = 56.497... r = ∛(710/4π) ≈ 3.837 cm

El único punto crítico (con r > 0) es r ≈ 3.837 cm.

5 Segunda derivada — verificar mínimo
C''(r) = 4π + 1420/r³ Evaluando en r = 3.837: C''(3.837) = 4π + 1420/(3.837)³ = 12.566 + 1420/56.51 ≈ 12.566 + 25.13 ≈ 37.70 > 0 ✓

Como C''(r) > 0, el punto crítico corresponde a un mínimo.

6 Respuesta final
r* ≈ 3.837 cm h* = 355/(π · (3.837)²) = 355/46.28 ≈ 7.672 cm h* = 2r* → La lata óptima tiene h = 2r (relación áurea del cilindro) C(r*) ≈ 2π(3.837)² + 710/3.837 ≈ 276.9 cm²

2
Cable tierra-isla
Minimizar costo total de tendido de cable terrestre y submarino
1 Contexto

Una isla está a 4 km de la costa. La fuente de energía en tierra está a 6 km a lo largo de la costa. El cable terrestre cuesta $1,500/km y el cable submarino $3,000/km. Se busca el punto óptimo sobre la costa para tender el cable hacia la isla.

Geometría: - Distancia isla-costa: 4 km (perpendicular) - Longitud total costa: 6 km - x = distancia terrestre desde la fuente hasta el punto de inmersión - Tramo submarino: √(16 + (6−x)²) [Pitágoras]
2 Función objetivo
C(x) = 1500x + 3000·√(16 + (6−x)²) donde: 1500x → costo cable terrestre 3000·√(16+(6−x)²) → costo cable submarino 0 ≤ x ≤ 6 km
3 Derivar la función
C'(x) = 1500 + 3000 · d/dx[√(16 + (6−x)²)] Usando regla de la cadena: d/dx[√(16+(6−x)²)] = [−2(6−x)] / [2√(16+(6−x)²)] = −(6−x) / √(16+(6−x)²) C'(x) = 1500 − 3000(6−x) / √(16 + (6−x)²)
4 Puntos críticos
Igualamos C'(x) = 0: 1500 = 3000(6−x) / √(16 + (6−x)²) (6−x) / √(16 + (6−x)²) = 1/2 Sea u = 6−x: u / √(16 + u²) = 1/2 2u = √(16 + u²) 4u² = 16 + u² 3u² = 16 u = 4/√3 ≈ 2.309 x* = 6 − 4/√3 ≈ 6 − 2.309 ≈ 3.691 km
5 Segunda derivada — verificar mínimo
C''(x) = −3000 · d/dx[−(6−x)/√(16+(6−x)²)] C''(x) = 3000 · 16 / [16+(6−x)²]^(3/2) En x* ≈ 3.691: (6−x*)² = (4/√3)² = 16/3 [16 + 16/3]^(3/2) = [64/3]^(3/2) ≈ 98.1 C''(3.691) = 3000 · 16 / 98.1 ≈ 489 > 0 ✓

C''(x) > 0 → mínimo confirmado.

6 Respuesta final
x* ≈ 3.691 km (cable terrestre desde la fuente) Cable submarino = √(16 + (6−3.691)²) = √(16 + 5.33) ≈ 4.619 km Costo mínimo total = 1500(3.691) + 3000(4.619) = 5,536.5 + 13,857 ≈ $19,393.5

3
Maximización de ingresos
Precio óptimo de suscripción para maximizar ingresos totales
1 Contexto

Un servicio de streaming tiene 4,000 suscriptores a $80/mes. Por cada $1 de aumento en el precio, se pierden 50 suscriptores. Se busca el aumento óptimo x para maximizar el ingreso total.

2 Función objetivo
Precio con aumento: P(x) = 80 + x Suscriptores restantes: N(x) = 4000 − 50x Ingreso total: I(x) = P(x) · N(x) = (80 + x)(4000 − 50x)
3 Derivar la función

Expandimos primero:

I(x) = (80 + x)(4000 − 50x) = 320,000 − 4,000x + 4,000x − 50x² = 320,000 + (−4000 + 4000)x − 50x² ¡Espera! Expandiendo correctamente: 80 · 4000 = 320,000 80 · (−50x) = −4,000x x · 4000 = 4,000x x · (−50x) = −50x² I(x) = 320,000 + (4,000 − 4,000)x − 50x² = 320,000 − 50x² ??? Re-expandiendo con cuidado: (80 + x)(4000 − 50x) = 80·4000 + 80·(−50x) + x·4000 + x·(−50x) = 320,000 − 4,000x + 4,000x − 50x² = 320,000 − 50x² Nota: los términos lineales se cancelan → I(x) = 320,000 − 50x² I'(x) = −100x
4 Puntos críticos
I'(x) = −100x = 0 → x* = 0 Interpretación: los términos lineales en I(x) se cancelaron exactamente, lo que significa que I(x) = 320,000 − 50x² es una parábola con vértice en x=0. Esto implica que cualquier aumento x > 0 REDUCE el ingreso. El ingreso máximo se logra con x = 0 (sin aumento). ANÁLISIS ADICIONAL: Si se permite reducción de precio (x < 0), la función tampoco mejora (también reduce por ser parábola invertida). Conclusión real: La estructura de la demanda es perfectamente balanceada.
Resultado matemático
x* = 0 → Ingreso máximo = $320,000 al precio actual de $80. Cualquier cambio de precio reduce el ingreso.
5 Segunda derivada — verificar máximo
I'(x) = −100x I''(x) = −100 I''(0) = −100 < 0 ✓ → Máximo confirmado

La segunda derivada es negativa en todo el dominio, confirmando que la función es cóncava hacia abajo y x = 0 es un máximo global.

6 Respuesta final
Aumento óptimo: x* = $0 Precio final: $80 + $0 = $80/mes Suscriptores finales: 4,000 − 50(0) = 4,000 Ingreso máximo: I(0) = $320,000/mes
